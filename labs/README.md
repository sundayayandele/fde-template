# Labs

One folder per curriculum week (`week-NN-<topic>/`). Each lab has:

| Section | Content |
| --- | --- |
| Goal | What you will be able to do, in one sentence |
| Brief | The customer-style problem for the week |
| Steps | Numbered steps; each names the files and TODOs to complete |
| Check | The command that proves it works (`make exercises`, a test file, or a smoke check) |
| Evidence | What to capture for your portfolio |
| Stretch | Optional extension, often on a second domain dataset |

Reference repos may keep worked solutions in `labs/<week>/solution*`; those paths are left out of the starter repo.
