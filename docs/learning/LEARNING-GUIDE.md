# Learning guide

> Phase repos replace this page with the phase's learning objectives, weekly plan and
> portfolio evidence, matching the curriculum in fde-zero-to-hired.

## How to use a phase repo

1. Start from the **starter repo** (`<repo>-starter`): "Use this template" on GitHub, then clone your copy.
2. Work through `labs/week-NN/` in order. Each lab has a brief, steps, and a check (usually `make exercises` or a smoke check).
3. When `make exercises` is green, run the desktop labs and at least one cloud lab.
4. Fill the README results table with your own measured numbers.
5. Write the customer brief and decision memo in `docs/customer/`.
6. Compare with the **reference repo** only after you have tried each exercise yourself.

## What a hiring manager will look for

- A results table with real numbers and how they were produced.
- The same system running on more than one platform.
- Clear trade-offs in an ADR and a decision memo.
- A customer brief a non-engineer can follow.
