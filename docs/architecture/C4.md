# C4 views

> Phase repos replace these diagrams with their own system at each level.

## Level 1: System context

```mermaid
C4Context
  title System context (template)
  Person(user, "Client", "Calls the API or runs the smoke test")
  System(svc, "FDE service", "FastAPI service built from fde-template")
  System_Ext(llm, "LLM provider", "Mistral by default; OpenAI, DeepSeek, Qwen, Kimi or self-hosted")
  Rel(user, svc, "HTTPS / JSON")
  Rel(svc, llm, "Chat completions", "HTTPS")
```

## Level 2: Containers

```mermaid
C4Container
  title Containers (template)
  Person(user, "Client")
  Container(api, "API", "Python, FastAPI, uvicorn", "Health, metrics, business endpoints")
  ContainerDb(secrets, "Secret store", "K8s Secret / Secrets Manager / Key Vault / Secret Manager", "LLM API keys")
  Container(prom, "Prometheus", "Metrics store", "Scrapes /metrics/")
  System_Ext(llm, "LLM provider")
  Rel(user, api, "HTTPS")
  Rel(api, secrets, "Reads keys at start-up")
  Rel(prom, api, "Scrapes")
  Rel(api, llm, "HTTPS")
```

## Level 3: Components (API)

| Component | Module | Responsibility |
| --- | --- | --- |
| HTTP layer | `app/main.py` | Routing, validation (Pydantic), metrics middleware |
| Settings | `src/fde_service/config.py` | Environment-driven configuration |
| LLM client | `src/fde_service/llm.py` | Provider selection, model per role, data-residency guard |
