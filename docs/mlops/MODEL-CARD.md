# Model card

> The template has no model. Phase repos with a model fill this in (fde-01 onwards).

- **Model:** name, version, base model and licence
- **Intended use:** task, users, setting; out-of-scope uses
- **Training data:** see `docs/datasets/DATASETS.md`
- **Evaluation:** see `docs/mlops/EVALUATION.md` and the README results table
- **Limitations and risks:** known failure modes, bias, safety findings
- **Owner and contact:** who maintains it
