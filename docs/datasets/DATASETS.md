## Rules

- Use a dataset only after its licence is verified from the source page or licence file.
- Non-commercial datasets are allowed for learning but flagged in the README.
- Run a PII check on free-text fields before storing or sending them to a model; record what is masked.
- Personal or regulated data is sent only to providers with `regulated_data_allowed: true`.
